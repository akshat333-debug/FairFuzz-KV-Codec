# Specification Traceability

This document maps the frozen specification components to concrete code paths.

## Modules
1. **Cache Capture**: `fairfuzzkv_codec.cache_capture`
2. **Unicode Grouping**: `fairfuzzkv_codec.unicode_grouping` (GroupMapper: grapheme segmentation, surface units, tokenizer alignment, quarantine, versioned audit report). Tested in `tests/unicode_grouping/`.
3. **Fragility Estimation**: `fairfuzzkv_codec.fragility_estimation` (per-group features, transparent monotone risk score as audit baseline, calibrated logistic/tree models validated against transparent baseline on held-out data, quantile risk cohorts with min-sample merge, cross-tokenizer stability, leakage enforcement). Tested in `tests/fragility_estimation/`.
4. **Pruning**: `fairfuzzkv_codec.pruning` (Prompt 9). Baseline selectors (recency, top-attention-mass, top-k token score) quantization-independent (`selectors.py`); group-aware selection with max/sum/normalized aggregation keeping surface groups coherent (`group_aware.py`); attention-mass repair contract enforcing local `p_E^repair <= p_E^0 + delta` per audited head/query with full accept/reject logging (`repair.py`); local per-head bound validator `||O-Ô||_2 <= 2·M·p_E` that reports assumption failures rather than manufacturing a pass (`bound.py`). Adversarial tests (concentrated attention, large value norms, duplicated subtokens, zero-attention groups) in `tests/pruning/`. **Local head-level only — not an end-to-end guarantee** (CLAIMS_LEDGER C-18/C-19).
   - **Module 3 — Fuzzy Repair-Priority Scorer (Prompt 13)**: `fairfuzzkv_codec.repair_scoring` — a documented, inspectable Mamdani fuzzy inference system (triangular membership functions, 10-rule base, min/max aggregation, centroid defuzzification, per-candidate rule traces: `fuzzy.py`) plus three non-fuzzy competitors on the identical normalized input contract (monotone weighted score, sigmoid score, knapsack value/cost ratio: `competitors.py`), train-only input normalization (`inputs.py`), a config-driven ablation registry (`ablation.py`), breakpoint/rule sensitivity analysis and latency/parameter complexity measurement (`sensitivity.py`), and drop-in integration with the UNCHANGED Prompt 9 `RepairContract` (`integration.py`). Tested in `tests/repair_scoring/`. Synthetic-candidate demo: `scripts/run_repair_scoring_demo.py` → `repair_scoring_study/`. Optional enhancement only — the codec is byte-identical if this module is removed.
   - **Gate 4 — Fuzzy-vs-Simple Ablation and Naming Decision (Prompt 14)**: `fairfuzzkv_codec.evaluation.gate4` (frozen PASS/WEAK_PASS/FAIL thresholds, tested pre-run in `tests/evaluation/test_gate4.py`) + `fairfuzzkv_codec.benchmarks.fragkv_minpairs.gate4_runner.Gate4Runner` (real KV + real attention capture via an `output_attentions=True` forward pass and a `q_proj` forward hook for one audited layer/head, real Module 1/2-derived candidate signals, budget-neutral repair via the UNCHANGED `RepairContract`) + `fairfuzzkv_codec.codec.explicit_mask.ExplicitMaskCodec` (caller-supplied retention mask, matched-bits-by-construction) + `fairfuzzkv_codec.core.naming` (automatic project name/claims switch driven by the frozen decision). Frozen config: `GATE4_CONFIG.md`. Real pilot study (Qwen2.5-0.5B, 80 pooled (example,budget,seed) cells): `scripts/run_gate4_study.py` → `gate4_fairness_study/` + `GATE4_REPORT.md` (**FAIL** — see RISK_REGISTER R-10 / CLAIMS_LEDGER C-23). Two report templates (`GATE4_REPORT_PASS_TEMPLATE.md`, `GATE4_REPORT_FAIL_TEMPLATE.md`) prepared before the run.
5. **Quantization**: `fairfuzzkv_codec.quantization` + `fairfuzzkv_codec.codec.scalar_quant.ScalarQuantCodec` (symmetric/asymmetric INT8/INT4, per-tensor/per-head/per-channel/groupwise granularity, percentile/MSE-optimal clipping, calibration-set selection, saturation diagnostics, genuine INT4 nibble packing, mixed K/V and per-layer/per-head bit-width configuration via `BitWidthMap`). Tested in `tests/quantization/` and `tests/codec/test_scalar_quant.py`. Real rate-distortion benchmark: `quantization_benchmark/` (K/V MSE and task-accuracy curves, Qwen2.5-0.5B).
   - **Vector Quantization (LBG)**: `fairfuzzkv_codec.quantization.vector_quant` + `fairfuzzkv_codec.codec.vector_quant.LBGVectorQuantCodec` (deterministic Linde-Buzo-Gray/k-means codebook training with split perturbation and empty-cluster recovery, head-block and cross-token vector formation, global/per-layer/per-head codebook scopes, calibration-fit leakage guard, chunked nearest-codeword encoding with optional FAISS behind a CPU-authoritative interface, serialized+counted codebook overhead, utilization/dead-code/error diagnostics). Tested in `tests/quantization/test_vector_quant.py`. Scalar-vs-LBG matched-total-bit benchmark: `lbg_benchmark/lbg_vs_scalar.json` (Qwen2.5-0.5B; reports small-corpus cases where codebook overhead makes VQ worse).
6. **Allocation**: `fairfuzzkv_codec.allocation` (Prompt 10 - aggregate-optimal control condition for Gate 2). Per-cohort distortion calibration with enforced train/val/test separation (`calibration.py`); distortion curves fitting `D(b)=alpha·exp(-beta·b)` only when diagnostics support it, else monotone-interpolation fallback (`curves.py`); aggregate allocator minimizing `sum_l D_l(b_l)` s.t. `sum_l cost_l(b_l) <= B` including fixed overhead, with exact DP reference solver and greedy water-filling approximation validated by optimality gap (`allocator.py`); handles infeasible budgets, minimum service levels, empty cohorts. Drives the REAL `ScalarQuantCodec` via `allocation_to_bitwidth_map`/`encode_with_allocation`. Live demo `scripts/run_allocation_demo.py` → `allocation_study/` (Qwen2.5-0.5B; exact==greedy gap 0.0, real encode within budget). Tested in `tests/allocation/`. NOTE: framed as a heuristic aggregate control, NOT premised on the Gate-1 causal claim (see RISK_REGISTER R-06 / PENDING.md).
   - **Minimax fairness allocator (Prompt 11)**: `fairfuzzkv_codec.allocation.minimax` - minimizes worst-cohort distortion at a fixed complete bit budget. Continuous water-filling derived from KKT conditions (`ALLOCATION_MATH.md`; the optimum equalizes achieved **distortion** across active cohorts, NOT beta) then projected to discrete scalar/LBG choices; exact epigraph reference solver (`solve_minimax_exact`) validates the production water-filling (`solve_minimax_waterfill`); supports max / weighted-max / minimum-quality objectives (max-distortion frozen default); reports worst/average distortion, Pareto frontier, and allocation shift vs the aggregate control. Frozen experiment config `GATE2_CONFIG.md`, live study `scripts/run_minimax_demo.py` → `gate2_study/`. Tested in `tests/allocation/test_minimax.py`.
7. **Metadata Coding**: `fairfuzzkv_codec.metadata_coding` (Prompt 8). FFKV binary format v1 (`container.py`: magic/version/endianness, geometry + tokenizer-hash header, section directory, per-section + geometry + whole-file CRC32, forward-compatible unknown-section skipping, bounds-checked safe rejection). Golomb-Rice retention coding (`golomb_rice.py`: blockwise-adaptive Rice over sorted gaps, with bitmap and run-length fallbacks selected by measured length; blockwise-Rice integer/zig-zag coders for indices/bit-width maps/cohort IDs/repair metadata; LEB128 varints). Byte-level spec + golden vectors: `FORMAT.md`. Tested in `tests/metadata_coding/` (incl. fuzz + golden-vector tests).
8. **Decoder/Reconstruction**: `fairfuzzkv_codec.decoder` (Prompt 8). `reconstruct.py`: `encode_to_container` / `decode_from_container` wrap either a scalar or LBG codec payload in an FFK1 container and reconstruct the cache tensor, with a `CompletenessReport` diagnostic (shape check, section presence). Tested in `tests/decoder/`.
9. **FragKV-MinPairs / Gate 1 Causal Test**: `fairfuzzkv_codec.benchmarks.fragkv_minpairs` (dataset generator, validators, immutable split hash, pre-registered Gate 1 decision logic, real-model runner via KV-cache splicing). Tested in `tests/benchmarks/fragkv_minpairs/`. Real 200-group study result: `gate1_study/GATE1_REPORT.md` (**WEAK_PASS** - see RISK_REGISTER R-06 and CLAIMS_LEDGER C-11).

10. **Gate 2 (Matched-Bit Fairness Experiment)**: `fairfuzzkv_codec.evaluation.disparity` / `.isolation` / `.gate2` (Prompt 12). Intersection-full-correct isolation subset, compression-induced degradation `Delta_{l,B}`, robust disparity metrics (CDDB = bounded std, absolute range, worst-group drop, mean, guarded ratio, risk-coverage), paired bootstrap CIs, and a PRE-REGISTERED PASS/WEAK_PASS/FAIL decision (frozen thresholds, tested on synthetic fixtures before the real run). Real pilot study: `scripts/run_gate2_study.py` → `gate2_fairness_study/GATE2_REPORT.md` (**FAIL** at pilot scale — negative evidence, see RISK_REGISTER R-09 / CLAIMS_LEDGER C-21). Frozen config: `GATE2_CONFIG.md`. Tested in `tests/evaluation/test_gate2.py`.

11. **IndicLongComp Parallel Multilingual/Code-Mixed Benchmark (Prompt 15)**: `fairfuzzkv_codec.benchmarks.indic_longcomp` — 4 language/code-mix conditions (en/hi/hinglish/te_en) x 5 task families (retrieval, multi-hop, comparison, counting, aggregation) from hand-designed parallel templates (`templates.py`, `generator.py`); parallelism verified structurally, not by translation-equivalence (`validators.py`); full dataset-card discipline including a real contamination self-check against FragKV-MinPairs (`dataset_card.py`); per-language fragility distributions reusing Module 2 unchanged (`fragility_report.py`); real FullKV baseline + intersection-full-correct isolation on Qwen2.5-0.5B, computed BEFORE any compression evaluation (`runner.py`). Course (10 groups, real FullKV run) + journal (250 groups, structurally validated only) subsets: `scripts/run_indiclongcomp_study.py` → `indic_longcomp_study/`, [INDICLONGCOMP_REPORT.md](INDICLONGCOMP_REPORT.md). Tested in `tests/benchmarks/indic_longcomp/`. Content is explicitly LLM-authored, not sourced from any external corpus (no verified MLRBench/network access) and not professionally reviewed — see the dataset card's `content_provenance_note`.

## Metric Families
- **Compression Efficiency**: Measured via exact byte accounting (not sparsity masks). Implemented in `fairfuzzkv_codec.codec.binary_serializer.ByteAccountant`, tested in `tests/codec/test_accounting.py`.
- **Reconstruction Error**: L2/MSE distortion via attention-equivalence check. Implemented in `fairfuzzkv_codec.benchmarks.attention_harness.AttentionVerificationHarness`, tested in `tests/cache_capture/test_hf_capture.py`.
- **Downstream Task Accuracy**: Exact match, F1 on real benchmark datasets. Not yet implemented — requires Dataset 1/2 integration above. Planned path: `fairfuzzkv_codec.evaluation.downstream` (Pending)
- **Throughput/Latency**: Prefill vs Decode speeds. Implemented in `fairfuzzkv_codec.evaluation.profiler.TelemetryTracker`.
