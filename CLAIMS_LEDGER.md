# Claims Ledger

This ledger tracks the scientific and engineering hypotheses made by the FairFuzzKV-Codec platform, and points to the empirical evidence (benchmarks/tests) that support or refute them.

| Claim ID | Claim Description | Validation Path | Status |
|---|---|---|---|

| C-02 | No-op codec round-trips FP16 KV-cache exactly (bit-identical). | `tests/codec/test_noop.py` | Validated |
| C-03 | Prefill and Decode execution paths are strictly separated. | `fairfuzzkv_codec/codec/base.py` | Implemented |
| C-04 | Real Hugging Face model KV-cache capture round-trips through a codec and reproduces attention output within tolerance. | `tests/cache_capture/test_hf_capture.py` | Validated |

| C-07 | Every non-special tokenizer subtoken is either aligned to a surface unit or explicitly quarantined, never silently dropped, across two distinct tokenizer families (byte-level BPE, SentencePiece). | `tests/unicode_grouping/test_aligner.py` | Validated |

| C-11 (Gate 1) | Tokenizer/evidence fragmentation (n_g) causally predicts additional compression-induced task failure, beyond a base-model confound. | `gate1_study/GATE1_REPORT.md`, `gate1_study/predictions.jsonl` (2400 real predictions, Qwen2.5-0.5B, 200 minimal-pair groups) | **WEAK_PASS**: only TopK50 shows a directionally-consistent, statistically significant (p=0.0004) effect (7.5 points, n_g=1→8), below the pre-registered 10-point "meaningful" bar; FullKV control itself collapses 48%→0% over the same range (non-monotonic), so the causal claim cannot be cleanly separated from a base-model confound at this scale. | C-12 | INT4 quantization is genuinely packed two values per byte (not stored one-per-byte in an int8 container). | `tests/quantization/test_packing.py`, `tests/codec/test_scalar_quant.py::test_int4_is_genuinely_packed_two_per_byte` | Validated |
| C-13 | All scale/zero-point/header overhead is counted in reported logical bits and serialized bytes - including groupwise scale tensors, which must stay compact (one value per group, not per element). | `tests/codec/test_scalar_quant.py::test_all_overhead_is_counted_in_reported_bits`, `test_groupwise_scale_storage_is_compact_not_per_element` | Validated (caught and fixed a real bug during development: groupwise scale was initially stored at full-element resolution, inflating bits/element from ~4 to ~68 - see RISK_REGISTER R-07) |
| C-14 | Scalar quantization round-trips are deterministic (identical input+config produce byte-identical output) and reject NaN input rather than silently propagating it. | `tests/codec/test_scalar_quant.py::test_deterministic_byte_output`, `test_nan_input_is_rejected` | Validated |
| C-15 | Rate-distortion curves for K, V, and real task-level accuracy are generated from a real captured cache and a real model, not synthetic/invented numbers. | `quantization_benchmark/benchmark_results.json`, `rate_distortion_mse.png`, `rate_distortion_task_distortion.png` (Qwen2.5-0.5B, 50 real FragKV-MinPairs groups) | Validated. See PENDING.md. |
| C-16 | LBG vector-quantization training and encoding are deterministic under a fixed seed, and the codebook overhead is serialized and fully counted in the reported bytes (so matched-total-bit comparisons against scalar are honest, and small-corpus cases where codebook cost makes VQ worse are reported, not hidden). | `tests/quantization/test_vector_quant.py`, `lbg_benchmark/lbg_vs_scalar.json` (Qwen2.5-0.5B) | Validated. Real finding, reported as-is: on a long corpus LBG-vd4-cb256 reached lower K MSE (0.73) at 2.24 eff bits/element than INT4-per_channel (1.63 MSE at 4.07 bits); on a tiny 3-token corpus the fixed codebook cost makes LBG infeasible/worse than scalar. |
| C-17 | The FairFuzzKV binary format v1 is a real versioned container (magic/version/endianness, geometry + tokenizer-hash header, section directory, CRC32 checksums, forward-compatible unknown-section skipping) - not a Python pickle - that decodes byte-identically across runs, rejects corrupt/truncated/checksum-failing/impossible inputs safely (never crashes on fuzzed bytes), and carries both scalar and LBG payloads. | `tests/metadata_coding/`, `tests/decoder/`, `FORMAT.md` (golden vectors) | Validated |
| C-18 | The attention-mass error bound ‖O − Ô‖₂ ≤ 2·M·p_E is a **LOCAL, single-head, single-layer** statement only - it is **NOT an end-to-end generation guarantee**. The validator reports assumption failures (e.g. an empty kept set makes renormalization undefined) rather than manufacturing a passing result. | `src/fairfuzzkv_codec/pruning/bound.py`, `tests/pruning/test_bound_and_repair.py` | Validated (local head-level only - do not cite as an end-to-end guarantee in the project report) |
| C-19 | The repair layer's accepted swaps never violate the configured local mass condition p_E^repair ≤ p_E^0 + delta for any audited head/query, and every accepted/rejected action is logged with its bound terms (M, p_E, delta, observed error, slack) inspectable per layer/head/query. This is a "repair does not worsen the baseline" contract, **not** a claim that repair improves end-to-end accuracy. | `tests/pruning/test_bound_and_repair.py` | Validated (local head-level only) |
| C-20 | The fairness-constrained minimax allocator's optimum **equalizes the achieved distortion D_l across active cohorts** (to the common worst-case value), **NOT** "beta" - beta_l are fixed curve parameters, not decision variables. The derivation (KKT conditions) is written out in `ALLOCATION_MATH.md` and matched by the implementation; the production water-filling solver matches the exact epigraph reference within tolerance; no allocation exceeds the encoded-bit budget; worst-cohort distortion is monotone non-increasing in budget; and the minimax worst-case is ≤ the aggregate control's worst-case at equal budget. | `ALLOCATION_MATH.md`, `tests/allocation/test_minimax.py`, `gate2_study/gate2_result.json` (Qwen2.5-0.5B, frozen `GATE2_CONFIG.md`) | Validated. The Pareto frontier is reported in full (worst vs average distortion across budgets), exposing the cost of fairness rather than hiding it. Minimax is an aggregate **engineering** control condition; it does not rely on the Gate-1 causal claim and is not a downstream-task-fairness claim. |
