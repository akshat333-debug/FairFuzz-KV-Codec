# Claims Ledger

This ledger tracks the scientific and engineering hypotheses made by the FairFuzzKV-Codec platform, and points to the empirical evidence (benchmarks/tests) that support or refute them.

| Claim ID | Claim Description | Validation Path | Status |
|---|---|---|---|
| C-01 | The system tracks exact byte usage, never substituting sparsity ratios for true memory cost. | `tests/codec/test_accounting.py` | Validated |
| C-02 | No-op codec round-trips FP16 KV-cache exactly (bit-identical). | `tests/codec/test_noop.py` | Validated |
| C-03 | Prefill and Decode execution paths are strictly separated. | `fairfuzzkv_codec/codec/base.py` | Implemented |
| C-04 | Real Hugging Face model KV-cache capture round-trips through a codec and reproduces attention output within tolerance. | `tests/cache_capture/test_hf_capture.py` | Validated |
| C-05 | The matched-bit evaluator refuses to return a codec when the target bits/element cannot be reached within tolerance. | `tests/evaluation/test_budget.py` | Validated |
| C-06 | The Unicode group mapper's surface units cover the original text exactly (no gaps/overlaps) and never split a grapheme cluster. | `tests/unicode_grouping/test_surface_units.py`, `tests/unicode_grouping/test_graphemes.py` | Validated |
| C-07 | Every non-special tokenizer subtoken is either aligned to a surface unit or explicitly quarantined, never silently dropped, across two distinct tokenizer families (byte-level BPE, SentencePiece). | `tests/unicode_grouping/test_aligner.py` | Validated |
| C-08 | Raw language/script labels and task/compression outcomes are structurally rejected before they can reach a fragility risk score or cohort assignment. | `tests/fragility_estimation/test_leakage_enforcement.py` | Validated |
| C-09 | Cohort quantile-band assignment is deterministic (identical reruns produce identical bands) and enforces a minimum-sample-size merge rule. | `tests/fragility_estimation/test_cohorts.py` | Validated |
| C-10 | A calibrated model (logistic/tree) is only worth using if its held-out AUC beats the transparent baseline's AUC on the same proxy-label split, measured on real held-out data, not asserted. | `tests/fragility_estimation/test_calibration_and_stability.py` | Validated (small-sample pilot: n≈100 units from a 7-sentence curated corpus; logistic/tree both beat the transparent baseline in this run, but sample size is too small to generalize — see RISK_REGISTER) |
| C-11 (Gate 1) | Tokenizer/evidence fragmentation (n_g) causally predicts additional compression-induced task failure, beyond a base-model confound. | `gate1_study/GATE1_REPORT.md`, `gate1_study/predictions.jsonl` (2400 real predictions, Qwen2.5-0.5B, 200 minimal-pair groups) | **WEAK_PASS**: only TopK50 shows a directionally-consistent, statistically significant (p=0.0004) effect (7.5 points, n_g=1→8), below the pre-registered 10-point "meaningful" bar; FullKV control itself collapses 48%→0% over the same range (non-monotonic), so the causal claim cannot be cleanly separated from a base-model confound at this scale. Do **not** cite fragmentation as a validated cause of compression failure in the project report — see RISK_REGISTER R-06. |
| C-12 | INT4 quantization is genuinely packed two values per byte (not stored one-per-byte in an int8 container). | `tests/quantization/test_packing.py`, `tests/codec/test_scalar_quant.py::test_int4_is_genuinely_packed_two_per_byte` | Validated |
| C-13 | All scale/zero-point/header overhead is counted in reported logical bits and serialized bytes - including groupwise scale tensors, which must stay compact (one value per group, not per element). | `tests/codec/test_scalar_quant.py::test_all_overhead_is_counted_in_reported_bits`, `test_groupwise_scale_storage_is_compact_not_per_element` | Validated (caught and fixed a real bug during development: groupwise scale was initially stored at full-element resolution, inflating bits/element from ~4 to ~68 - see RISK_REGISTER R-07) |
| C-14 | Scalar quantization round-trips are deterministic (identical input+config produce byte-identical output) and reject NaN input rather than silently propagating it. | `tests/codec/test_scalar_quant.py::test_deterministic_byte_output`, `test_nan_input_is_rejected` | Validated |
| C-15 | Rate-distortion curves for K, V, and real task-level accuracy are generated from a real captured cache and a real model, not synthetic/invented numbers. | `quantization_benchmark/benchmark_results.json`, `rate_distortion_mse.png`, `rate_distortion_task_distortion.png` (Qwen2.5-0.5B, 50 real FragKV-MinPairs groups) | Validated. Notable real finding, reported as-is: at 8 bits/element, per-tensor granularity scored HIGHER task accuracy (84%) than per-channel (78%) despite per-channel having far lower K MSE (0.013 vs 0.234) - MSE does not always predict task accuracy at this sample size. See PENDING.md. |
